# Internet Controlled RC Car 🚗

A Wi-Fi enabled RC car that can be controlled remotely through a web interface using IoT and cloud integration.

---

## 🚀 Features

- Remote control via web browser  
- Real-time communication using Firebase  
- Internet-based control (not limited to local network)  

---

## 🛠️ Tech Stack

- ESP8266 / ESP32  
- Arduino  
- Firebase Realtime Database  
- HTML, CSS, JavaScript  

---

## ⚙️ System Architecture

User → Web Interface → Firebase → ESP Module → Motor Driver → RC Car

---



## ⚙️ Setup Instructions

1. Upload Arduino code to ESP module  
2. Connect motors and driver circuit  
3. Configure Firebase credentials  
4. Open web interface to control the car
